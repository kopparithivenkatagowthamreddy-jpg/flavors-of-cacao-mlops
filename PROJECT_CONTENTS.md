# Project folder contents

- `data/raw/`: original Flavors of Cacao CSV dataset.
- `data/processed/`: cleaned dataset and preprocessing metadata, generated by `python -m src.preprocess`.
- `models/`: serialized trained Random Forest regression pipeline, generated by `python -m src.train`.
- `outputs/`: evaluation metrics and prediction results, generated by `python -m src.evaluate`.
- `artifacts/`: preprocessing metadata, train/test split metadata, and workflow run record.
- `logs/`: console output and exit status from the workflow commands.
- `src/`: reusable preprocessing, training, evaluation, and validation code.
- `pipelines/`: end-to-end and lab-specific workflow entry points.
- `notebooks/`: original notebook and its saved notebook model artifact.

To regenerate the main supporting outputs from the project root, run:

```powershell
python -m src.validate_data
python -m src.preprocess
python -m src.train
python -m src.evaluate
```

- `models/`: serialized model pipelines for all five regression models.
- `outputs/model_comparison.csv`: the comparison metrics provided from the notebook run.
- `outputs/model_comparison_latest.csv`: freshly measured metrics generated by `src.train_all_models`.
- `src/train_all_models.py`: trains and saves all five model pipelines.

## Model artifacts

The `models/` directory includes saved pipelines for:
- `linear_regression.joblib`
- `ridge_regression.joblib`
- `random_forest.joblib`
- `tuned_random_forest.joblib`
- `gradient_boosting.joblib`

The `outputs/` directory includes:
- `model_comparison.csv`: comparison values reported from the user's notebook.
- `model_comparison_latest.csv`: metrics measured when the model-training script was last run.
- `model_comparison_notes.txt`: explains the distinction between the two comparison tables.
